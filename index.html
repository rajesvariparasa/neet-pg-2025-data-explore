About this data

This is an independent data-exploration tool and is not affiliated with or endorsed by the Medical Counselling Committee (MCC).

The data presented here has been extracted from publicly available MCC counselling documents and PDFs. I check the extracted data against the original source material on a best-effort basis, but this is a single-person project and errors or omissions may remain.

The underlying extracted dataset and the code used to build this explorer are publicly available: extracted data · GitHub repository

This site is intended for exploration and analysis only. For official information, counselling rules, seat availability, allotment results, and decisions with significant consequences, please refer to the latest information published directly by MCC and verify the relevant details against the original source documents.
